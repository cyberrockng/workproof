The active implementation is Solidity plus Go. Python and TypeScript scaffold paths remain in the repo for reference but are not the active WorkProof verifier.

Local setup

Run these from a fresh clone before local tests or Coston2 work.

bash ./scripts/bootstrap.sh
forge test
cd go && go test ./...
cd tools && go test ./...
cd relayer && npm test

Smart contract

`contracts/WorkProofEscrow.sol` owns the escrow lifecycle and dispatches FCC VERIFY instructions.

Go verifier

`go/internal/verifier` decrypts bundles, cross-checks chain state, executes vectors, and returns VerdictV1.

Relayer

`relayer/src/relay.js` submits signed FCC results without holding escrow authority.
